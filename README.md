# Astria

面向 UE5 特效师、VFX、TA、动画和 Shader 艺术家的逐帧视频分析播放器。项目同时支持 Electron Windows 桌面应用和零依赖浏览器版本。

## Windows 桌面版

### 直接安装

构建产物位于：

- `out/builder/Astria-Setup-0.8.8.exe`：可选择安装位置与桌面快捷方式的 Windows 安装向导
- `out/builder/Astria-0.8.8-x64.zip`：免安装便携包

当前开发构建尚未购买代码签名证书，Windows SmartScreen 可能在首次运行时显示未知发布者提示。

### 开发运行

```powershell
npm install
npm start
```

### 验证与构建

```powershell
npm run check
npm run smoke
npm run package
npm run make:win
```

桌面版使用 Electron 沙箱渲染、`contextIsolation` 和白名单 preload 接口。视频文件由系统原生选择器打开；播放器偏好使用独立小文件，每个媒体的书签、批注、循环区间和播放进度分别保存，缩略图也会拆成独立图片，避免大型项目反复传输和序列化整库数据。播放进度记忆默认开启，也可在播放设置中关闭；再次打开媒体时会先呈现上次位置的缓存画面，并让播放核心直接从该位置载入。应用支持最近视频、单实例启动、系统菜单、原生工作区导出和命令行视频打开。

## 浏览器版本

直接打开 `index.html`，或使用任意静态文件服务器访问项目目录。浏览器版本继续使用浏览器本地存储，不依赖 Electron。

## 已实现

- 视频打开、拖放、点击画面播放/暂停、倒放、0.05× 精度变速、音量和全屏
- 画面拖动和时间轴实时逐帧 Scrub，`Shift` 慢速、`Alt` 为 1 像素 1 帧
- 视频自动完整适配横屏、竖屏和特殊比例，支持适应窗口、1:1、缩放与平移
- `I` / `O` 设置 A/B 循环区间，`Shift + I/O` 清除区间点
- 约 64 MiB 的按需帧缓存与邻近帧即时预览（暂停、倒放和拖动时启用）
- 融合刻度与缩略图的标准时间轴，以及约 26px 高的无缩略图紧凑模式；可分别关闭轨道缩略图和悬停大图，精确调节预览尺寸，并支持密度、构图、定位、自动跟随、`Ctrl + 滚轮` 缩放及一键恢复
- 书签缩略图、标题、颜色、标签、收藏、评分和 Markdown 笔记
- 右键环形批注菜单，包含浏览/Scrub、箭头、圆形、矩形、画笔、文字、高亮、橡皮擦、颜色和粗细
- 每帧批注聚合、批注缩略图、时间轴标记、全部批注视图和批注帧跳转
- 按视频指纹隔离并恢复书签、批注、笔记和循环区间
- LUMA 明暗检查、50%–200% 对比度调节和一键恢复
- WebGL2 64³ LUT SDR 查看预设：原始、UE5 Filmic、Unity Neutral / ACES、ACEScg 与 ACES2065-1；预设按视频保存，截图与缩略图始终保留原始帧
- 三分线、中心十字、Action/Title Safe 与常用宽高比遮罩，支持透明度、遮罩强度和可自定义的 `H` 键总开关
- 书签、批注帧或 I/O 区间取样生成高清 PNG Contact Sheet，支持逐帧选择、批注、分页、进度与取消
- 默认隐藏、按需固定展开的书签/批注/属性面板
- 紧凑播放栏和时间轴，媒体信息集中在顶部且不遮挡画面
- 可配置播放结束后停留、返回首帧或循环播放
- 纯净模式：隐藏常驻界面，鼠标移动时同步显示鼠标、悬浮播放栏与轻量时间轴；时间轴支持拖动、批注、书签及 A/B 标记
- 可用 `X` 开关、锁定并复制颜色信息的拾色工具，以及带批注帧 PNG 导出
- 可自定义快捷键，默认 `D` / `F` 逐帧、`Ctrl + 0` 复原画面比例
- 可关闭的实时自动保存、工作区保存状态、工作区 JSON 导出、帧截图复制与下载
- Windows 原生文件选择、最近文件、视频扩展名关联、默认应用入口、应用菜单、磁盘持久化和安装包
- 从系统文件关联冷启动时等待首帧就绪后再显示窗口，避免空播放器界面闪现
- Windows 沉浸式标题栏，以及最大化状态下的任务栏安全区保护

## 当前播放核心

Windows x64 桌面版使用 Electron **40.10.5** 与 LGPL **libmpv v0.41.0**。主路径为 GPU 共享纹理；GPU 初始化或共享失败自动降级到 WebGL2 软件帧上传。缺失或损坏的核心会明确报错，不回退 Chromium。浏览器继续使用 HTMLVideo，格式能力保持浏览器原有范围。

支持 ProRes、DNxHD/DNxHR、10-bit HEVC、MXF、M2TS、WMV 等格式。扩展名只用于筛选与关联，未知扩展名仍按内容探测；不支持网络流和专有相机 RAW。输出目标是 Rec.709/BT.1886、100 nit SDR，HDR 与线性素材按可用元数据转换，不启用系统 HDR 或任意 OCIO。

EXR、DPX、PNG、JPEG 单图及序列按同目录“前缀＋固定位数数字＋扩展名”识别。缺帧保留时间位置、沿用上一有效帧并显示缺失提示；显示源帧号，工作区仍保存零基索引。序列默认 24 FPS，可沿用帧率输入框修改。新增帧不会改变序列工作区标识。PNG/JPEG 不注册系统文件关联。

原生核心的重建步骤、依赖锁定与动态库替换说明见 [native/README.md](native/README.md)，许可证和源代码归档见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。桌面烟雾检查使用 `.cache/media/h264.mp4`，也可通过 `ASTRIA_SMOKE_MEDIA` 指定本地代表素材；检查使用独立配置目录。
